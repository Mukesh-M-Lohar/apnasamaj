# ApnaSamaj – Project Roadmap

This document outlines the development phases for the ApnaSamaj platform, a modular, mobile-first community management system.

## Completed Phases ✅

### Core & Infrastructure
- **Phase 1**: Core Infrastructure, Security, Settings, and Base Models
- **Phase 2**: Authentication (OTP, JWT, Multi-Device)
- **Phase 3**: Community (Tenant) Management

### Modules (Backend)
- **Phase 4**: Member & Family Management (Directory, Family Trees)
- **Phase 5**: Committees, Role Mapping, and Bulk Import
- **Phase 6**: Donation Management (Ledger, Receipt Generation)
- **Phase 7**: Event Management (Scheduling, RSVPs, Attendance)
- **Phase 8**: Volunteer Management (Profiles, Skill Tracking, Hours Rollup)

### Frontend (Mobile)
- **Phase 9**: Mobile App Setup (React Native/Expo Scaffolding, Auth Store)
- **Phase 10**: Mobile App UI Expansion (Navigation, Member Directory, Donations Ledger)

---

## Upcoming Phases 🚀

### Backend Expansion
- **Phase 11: Complaint & Ticketing Management**
  Members can raise issues (maintenance, disputes, suggestions), assign them to specific committees, and track their resolution status.
- **Phase 12: Facility & Asset Booking**
  A module to manage and book community assets (e.g., community halls, sports courts, parking spaces) with collision detection.
- **Phase 13: Communications & Broadcasting**
  A unified notification module (integrating Push Notifications, SMS, or Email) to broadcast announcements or event reminders to members.
- **Phase 14: Polling & Surveys**
  Allowing committees to run digital votes for community decisions (e.g., electing committee heads, deciding on event budgets).

### Frontend Expansion
- **Phase 15: Web Admin Dashboard (React/Next.js)**
  A powerful desktop web portal for community admins to visualize data, manage users, and export reports.
- **Phase 16: Payment Gateway Integration**
  Upgrading the Donations ledger from manual entry to automated processing by integrating Razorpay, Stripe, or UPI deep-links.
- **Phase 17: Mobile App Expansion**
  Building out the remaining mobile UI screens for Family Trees, Event RSVPs, and Complaint tracking.
